# Tools

Use tool references to look up validation-relevant command behavior,
operational effects, evidence, and blind spots. They are not complete command
manuals and do not choose a validation strategy.

1. [Cargo](cargo.md) — checking, testing, documentation, and packaging evidence.
2. [Clippy](clippy.md) — lint selection, targets, output, and static-analysis limits.
3. [Git](git.md) — stable status observations and mutation blind spots.
4. [pnpm](pnpm.md) — dependency, script, and project-local executable behavior.
5. [rustfmt](rustfmt.md) — non-mutating Rust formatting checks.
6. [TypeScript Compiler](typescript-compiler.md) — project-scoped static checking without emission.
7. [Vitest](vitest.md) — one-shot configured test execution.
