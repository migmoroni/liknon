# Framework Profile

- Kind: `framework`
- Family: `explanation`
- Editorial bases: `oasis-dita-1.3-errata-02`, `diataxis`, `google-developer-documentation-style-guide`, `microsoft-writing-style-guide`

## Purpose And Basis

A framework guide explains validation behavior introduced by a framework. It
uses DITA concept, Diataxis explanation, and shared clarity guidance.

## Structure

Use Role And Scope, Framework-Specific Failure Modes, Validation Layers,
Evidence And Limitations, Version Scope, Related Tools And Recipes, and Next
Step. All are required.

## Depth Version And Example

Do not teach the framework or repeat its language guide. Cover maintained major
lines only when behavior changes evidence selection. No framework guide is
created until a demonstrated reader question has authoritative coverage.

## Review Checklist

Confirm a framework-specific question, distinct failure surfaces, layered
evidence, explicit limits, material version distinctions, operational effects,
and links rather than duplicated language guidance. Apply the shared rubric.
