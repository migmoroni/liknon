# Foundation Profile

- Kind: `foundation`
- Family: `explanation`
- Editorial bases: `iso-iec-ieee-26514-2022`, `oasis-dita-1.3-errata-02`, `diataxis`, `google-developer-documentation-style-guide`, `microsoft-writing-style-guide`

## Purpose And Basis

A foundation answers a recurring conceptual question and establishes shared
vocabulary. It applies DITA concept orientation and Diataxis explanation,
guided by ISO audience and information-quality principles and the two clarity
style guides. This is a local profile, not a claim of full conformance.

## Structure

Use the exact H2 order in `editorial-profiles.json`: Question, Applicability And
Boundaries, Conceptual Model, Decision Guidance, Evidence And Limitations, and
Related Knowledge. All sections are required.

## Depth Version And Example

Explain only the conceptual model needed for a validation decision. Do not turn
the guide into a procedure, tool reference, or theory chapter. Prefer stable
concepts; identify an edition only when it changes the model. A guide that asks
when a check supports a claim fits this profile.

## Review Checklist

Confirm one question, consistent vocabulary, explicit boundaries, proportional
decision guidance, evidence limits, adjacent citations, and links instead of
duplicated explanations. Apply the shared review rubric.
