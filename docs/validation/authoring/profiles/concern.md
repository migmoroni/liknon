# Concern Profile

- Kind: `concern`
- Family: `explanation`
- Editorial bases: `iso-iec-ieee-26514-2022`, `oasis-dita-1.3-errata-02`, `diataxis`, `google-developer-documentation-style-guide`, `microsoft-writing-style-guide`

## Purpose And Basis

A concern bounds one cross-cutting risk and the evidence needed to respond. It
uses DITA concept with a bounded troubleshooting shape, Diataxis explanation,
ISO consequence-oriented user needs, and shared clarity rules.

## Structure

Use Risk And Applicability, Consequences, Required Evidence, Limitations, Cost
Mutation And External Services, and Response And Next Step. All are required.

## Depth Version And Example

Connect consequences to evidence without prescribing a fixed tool stack. Name
residual uncertainty and ecosystem-specific examples only through related
guides. Reproducible release evidence fits; a Cargo command manual does not.

## Review Checklist

Confirm a single risk, bounded applicability, consequence severity, sufficient
evidence categories, limitations, operational effects, proportionate response,
and adjacent source support. Apply the shared review rubric.
