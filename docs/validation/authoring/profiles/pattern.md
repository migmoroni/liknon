# Pattern Profile

- Kind: `pattern`
- Family: `explanation`
- Editorial bases: `iso-iec-ieee-26514-2022`, `oasis-dita-1.3-errata-02`, `diataxis`, `google-developer-documentation-style-guide`, `microsoft-writing-style-guide`

## Purpose And Basis

A pattern explains one reusable evidence-design solution. It uses DITA concept
and Diataxis explanation, ISO consistency, and the shared clarity rules. The
context-forces form is a local software-pattern profile, not a DITA or Diataxis
definition.

## Structure

Use Problem And Context, Forces, Pattern, Consequences And Tradeoffs, Example,
Failure Modes, and Related Knowledge in the registry order. All are required.

## Depth Version And Example

State when the pattern helps, conflicts among forces, and when its cost or
uncertainty makes it unsuitable. Keep examples bounded and version-neutral. An
evidence chain connecting a claim, mechanism, observation, and oracle fits.

## Review Checklist

Confirm explicit forces, actionable pattern steps, both benefits and costs, a
non-universal example, concrete failure modes, citations, and no duplicated
foundation material. Apply the shared review rubric.
