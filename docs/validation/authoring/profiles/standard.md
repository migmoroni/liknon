# Standard Profile

- Kind: `standard`
- Family: `reference`
- Editorial bases: `oasis-dita-1.3-errata-02`, `diataxis`, `rfc-7322`, `rfc-8174`, `google-developer-documentation-style-guide`, `microsoft-writing-style-guide`

## Purpose And Basis

A standard reference preserves an external publication's authority, version,
terminology, levels, and conformance meaning. It uses DITA and Diataxis
reference, RFC 7322 precision for normative summaries, RFC 8174 only for
intentional uppercase keywords, and shared clarity guidance.

## Structure

Use Authority Scope And Version, Native Terminology And Conformance,
Applicability, Evidence And Limitations, Misuse To Avoid, and Sources And Next
Step. All are required.

## Depth Version And Example

Point to the authoritative publication instead of reproducing it. Never invent
local conformance levels or treat automation as complete conformance proof.
WCAG 2.2 retains its exact edition because the version is intrinsic.

## Review Checklist

Confirm authority type, exact edition, native terminology, applicability,
evidence limits, misuse warnings, adjacent citations, and no accidental local
normative claim. Apply the shared rubric.
