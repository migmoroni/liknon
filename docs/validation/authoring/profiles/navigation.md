# Navigation Profile

- Kind: `navigation`
- Family: `navigation`
- Editorial bases: `iso-iec-ieee-26514-2022`, `oasis-dita-1.3-errata-02`, `diataxis`, `wcag-2.2`

## Purpose And Basis

A family or category index helps readers find the right guide without adding a
second source of substantive guidance. It adopts DITA map/navigation concepts,
ISO findability, Diataxis separation by reader purpose, and WCAG meaningful
link structure.

## Structure

Use one H1, a concise reader-intent and boundary statement, and one ordered list
of every direct child guide or category with a descriptive summary. Add routing
to adjacent families only when useful. Navigation assets have no document IDs.

## Depth Version And Example

An index may say that tool references explain command behavior and then list
the available tools. It must not recommend a particular command or copy version
tables from a guide.

## Review Checklist

Confirm complete and deterministic child listing, descriptive links, accurate
boundaries, no independent recommendations, no vague link text, and useful
adjacent-family routing. Apply the shared rubric.
