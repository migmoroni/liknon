## Purpose And Basis

A recipe helps a reader accomplish one bounded validation goal in an adaptable
sequence. It applies DITA task, Diataxis how-to, ISO task orientation, and the
shared procedural-writing guidance.

## Structure

Use Goal, Applicability And Preconditions, Risks And Invariants, Inputs And
Workspace Assumptions, Procedure, Complete Configuration Example, Expected
Evidence, Failure Interpretation, and Limitations And Residual Risk. All are
required.

## Depth Version And Example

Provide enough detail to adapt and execute one internally consistent,
non-publishing composition. Declare capabilities and major-line assumptions,
label placeholders, and avoid private repository layout. A general Rust CLI
release gate cannot validate liknon-only assets.

## Review Checklist

Confirm prerequisites, ordered actions, safe effects, exactly one complete JSON
configuration, expected outcomes, failure meaning, residual risk, version
assumptions, and no claim of universal policy. Apply the shared rubric.
