# Tool Profile

- Kind: `tool`
- Family: `reference`
- Editorial bases: `oasis-dita-1.3-errata-02`, `diataxis`, `google-developer-documentation-style-guide`, `microsoft-writing-style-guide`

## Purpose And Basis

A tool reference describes behavior needed to select a validation mechanism and
interpret its evidence. It applies DITA reference, Diataxis reference, and the
shared command and technical-reference style guidance.

## Structure

Use Purpose And Scope, Version Lines And Sources, Command Model, Inputs Outputs
And Exit Status, Mutation Cost And External Services, Evidence Produced, Blind
Spots, and Related Knowledge. All are required.

## Depth Version And Example

Do not reproduce a command manual. Show only representative forms. List
material maintained major lines and tell readers to confirm the active version.
Exact reviewed patches remain source provenance. A pnpm guide covers lines 11
and 12 rather than identifying itself as one patch.

## Review Checklist

Confirm version lines and sources, command selection, inputs and exits,
mutation/cost/network effects, evidence meaning, blind spots, descriptive code
introductions, and routing to concepts and recipes. Apply the shared rubric.
