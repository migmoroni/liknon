# Technology Profile

- Kind: `technology`
- Family: `explanation`
- Editorial bases: `oasis-dita-1.3-errata-02`, `diataxis`, `google-developer-documentation-style-guide`, `microsoft-writing-style-guide`

## Purpose And Basis

A technology guide explains validation behavior introduced by a runtime,
protocol, platform, storage system, or technical environment. It applies DITA
concept, Diataxis explanation, and the shared clarity rules.

## Structure

Use Role And Scope, Failure Modes, Validation Surfaces, Evidence And
Limitations, Version Scope, Related Knowledge, and Next Step. All are required.

## Depth Version And Example

Cover only surfaces that change validation. Do not duplicate language or tool
material. Node.js belongs here because host modules and process behavior differ
from ECMAScript semantics. Use major-line scope when material.

## Review Checklist

Confirm the technical role, environment-specific failures, observable
surfaces, evidence limits, version policy, effects, source support, and clear
routing to language and tool guides. Apply the shared review rubric.
