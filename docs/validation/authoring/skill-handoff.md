# Liknon Skill Handoff

The source under `skills/liknon/` is preserved as design input for C02. It is
not an active or distributable skill at the A01 boundary.

Its manifest, router, and workflow documents record useful interaction and
safety requirements, but their command examples predate the separated Liknon
applications. Consumers must not treat those examples as current CLI guidance.
C02 owns any future activation, command reconciliation, packaging, and
distribution of this material.

Until that work is complete, the maintained CLI documentation is the source of
truth for available commands.
