# Editorial Bases

The local editorial system adopts only the aspects named here. A source's
authority type is preserved; a methodology or corporate style guide is not
presented as a formal standard.

## ISO IEC IEEE 26514 2022

- ID: `iso-iec-ieee-26514-2022`
- Authority type: formal international standard
- Scope: ISO/IEC/IEEE 26514:2022, reviewed 2026-10-01
- Official URI: [IEEE 26514-2022](https://standards.ieee.org/ieee/26514/11031/)
- Adopted: audience analysis, information quality, consistency, lifecycle,
  findability, and maintainability.
- Not claimed: full process, deliverable, or conformance implementation.

It informs foundation, pattern, concern, recipe, and navigation profiles.

## OASIS DITA 1.3 Plus Errata 02

- ID: `oasis-dita-1.3-errata-02`
- Authority type: formal OASIS standard
- Scope: DITA 1.3 plus Errata 02, final publication
- Official URI: [DITA 1.3 overview](https://docs.oasis-open.org/dita/dita/v1.3/errata02/os/complete/part0-overview/dita-v1.3-errata02-os-part0-overview-complete.html)
- Adopted: topic orientation; concept, task, reference, troubleshooting, and
  map/navigation distinctions.
- Not claimed: DITA XML vocabulary, processing, specialization, or full
  conformance.

It informs every content profile and the navigation profile.

## Diataxis

- ID: `diataxis`
- Authority type: documentation methodology
- Scope: public methodology reviewed 2026-10-01
- Official URI: [Diataxis](https://diataxis.fr/)
- Adopted: separation of explanation, how-to, reference, and tutorial purposes.
- Not claimed: formal-standard authority or complete methodological adoption.

It informs every profile. This corpus has no tutorial family because it has no
demonstrated tutorial journey.

## Google Developer Documentation Style Guide

- ID: `google-developer-documentation-style-guide`
- Authority type: public technical-writing style guide
- Scope: living guide reviewed 2026-10-01
- Official URI: [Google developer style](https://developers.google.com/style)
- Adopted: direct language, active voice, reader-oriented instructions,
  terminology, headings, and code presentation.
- Not claimed: Google product terminology or complete house-style conformance.

It informs every substantive content profile.

## Microsoft Writing Style Guide

- ID: `microsoft-writing-style-guide`
- Authority type: public technical-writing style guide
- Scope: living guide reviewed 2026-10-01
- Official URI: [Microsoft Writing Style Guide](https://learn.microsoft.com/en-us/style-guide/welcome/)
- Adopted: clarity, concision, inclusive language, scannability, and consistent
  technical terminology.
- Not claimed: Microsoft product voice or complete house-style conformance.

It informs every substantive content profile.

## RFC 7322

- ID: `rfc-7322`
- Authority type: RFC editorial standard
- Scope: RFC 7322, September 2014
- Official URI: [RFC 7322](https://www.rfc-editor.org/rfc/rfc7322.html)
- Adopted: precise structure when summarizing normative technical material.
- Not claimed: publication as an RFC or full RFC editorial compliance.

It informs the standard reference profile.

## RFC 8174

- ID: `rfc-8174`
- Authority type: Internet Best Current Practice
- Scope: BCP 14, RFC 8174, May 2017
- Official URI: [RFC 8174](https://www.rfc-editor.org/rfc/rfc8174.html)
- Adopted: uppercase normative keywords only when a local normative contract
  intentionally invokes their defined meaning.
- Not claimed: that ordinary recommendations are BCP 14 requirements.

It informs the standard reference profile.

## WCAG 2.2

- ID: `wcag-2.2`
- Authority type: W3C Recommendation
- Scope: WCAG 2.2 Recommendation, 5 October 2023
- Official URI: [WCAG 2.2](https://www.w3.org/TR/WCAG22/)
- Adopted: accessible structure, meaningful links, readable language, and no
  dependence on visual presentation alone.
- Not claimed: that editorial validation proves WCAG conformance.

It informs the navigation profile and global accessibility rules.
